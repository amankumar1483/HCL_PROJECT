WEATHER TREND ANALYSIS - BASIC PYTHON PROJECT

Project level:
Beginner level using Python, NumPy and Pandas.

Files:
1. weather_analysis.py - Main Python program
2. weather_data.csv - Sample weather dataset
3. requirements.txt - Required Python libraries

How to run in VS Code:
1. Extract this ZIP file.
2. Open the extracted folder in VS Code.
3. Open Terminal > New Terminal.
4. Install the libraries:

   pip install -r requirements.txt

5. Run the project:

   python weather_analysis.py

Note:
This is a small sample dataset containing five illustrative days.
It is for learning and demonstration, not official weather data
or a real weather forecast.
